## Description
This is the backend for the SE23 Web Project, developed as part of the Web Technologies course (Fall 2025).  
It handles the server-side functionality including managing books, categories, orders, carts, and user authentication.

## Technologies Used
- C# / ASP.NET Core
- Entity Framework Core
- SQL Server
- Git / GitHub

## Features
- Admin panel for managing books, categories, and orders
- CRUD operations for all models
- User authentication and authorization
- RESTful API endpoints
